PIXELATOR

Pixelate photos and video against a palette you control.

Set the block grid, pick the colours it is allowed to use, and watch the result redraw as you drag. It runs in the browser with no server behind it: your images are never uploaded, and there is no account to make.

What it is

Runs on
Any current browser. The Android build is a Capacitor wrapper around these same files, kept outside this repository.
Network
None. No uploads, no analytics, no fonts or scripts fetched from anywhere. It works with the network off.
Accounts
None. Palettes live in localStorage as plain { name: ["#RRGGBB", …] }, and export to a JSON file you can move between devices yourself.
Input
Images for the photo and extract screens; MP4 or WebM for video.
Output
PNG for stills. MP4 for video where WebCodecs is available, WebM otherwise.
Ships with
Gameboy, CGA and Grayscale palettes, six themes, and no runtime dependencies beyond one vendored MP4 muxer.
Tests
59 checks over the pixelation, palette-mapping, blending and extraction code, runnable with node and no test framework.

How it works

Pixelation

Each image is reduced to a grid of blocks with a box filter — every block is the true average of the pixels underneath it, not a sample of one of them — and each block is then replaced by the nearest colour in the palette, measured in RGB.

Nearest-colour search is exact for small jobs. Above roughly 40,000 pixels per frame, or palettes over 24 colours, it builds a lookup table over a 32×32×32 colour cube instead: a fixed cost up front, then one probe per pixel. The threshold is where the table stops being the more expensive option.

The two block-size sliders are locked to the source aspect ratio. Dragging one drives the other and freezes it for the duration of the gesture, so a second finger cannot fight the first.

Their limits come from the image rather than from a fixed list: the grid runs from 32 blocks across the picture's shorter side up to 1920 across its longer one, so a 16:9 photo offers 57–1920 horizontally against 32–1080 vertically. Both sliders therefore hit their ends together, and neither can be dragged somewhere the other cannot follow.

Where palettes come from

You can build one by hand, paste a list of hex codes, or pull one out of an image on the Extract screen, which offers two different answers to "what colours is this picture made of".

Frequency peaks counts pixels in the colour cube and takes the most populous. A matching radius lets nearby shades reinforce one another rather than compete, and a minimum separation stops the result being six versions of the same blue.

k-means++ clusters the colours instead, which gives a more even spread across the image at the cost of picking colours that may not literally appear in it.

Neither is saved until you press save, so you can re-extract as often as you like while you compare.

Video

Video is the part that has to be careful. Frames are decoded, reduced, blended and encoded one at a time rather than being collected first, which matters more than it sounds: the temporal smoothing only needs the previous blended frame to produce the next, so a whole clip never has to exist in memory at once.

A 3-minute clip at 1024 blocks wide: ~28.5 GB held as a frame stack, ~13 MB streamed — with identical output.

Where the browser supports WebCodecs, frames are written to MP4 with explicit timestamps, so encoding runs as fast as the machine manages and the output timeline is exact. Where it does not, it falls back to MediaRecorder, which timestamps by wall clock and therefore records in real time; the app says which path it took and warns you if it fell behind.

Low frame rates are treated as a look rather than a limitation. An 8 fps result is written as a 24 fps file with each frame held three times — visually identical, but it plays properly everywhere instead of stuttering in players that dislike 8 fps containers.

Running it yourself

The app is static files. Clone the repository and serve the folder:

git clone https://github.com/GeorgiosAnastasiou/video_pixelator
cd video_pixelator
python3 -m http.server 8000

Then open http://localhost:8000. A plain file:// open will not work — the app is made of ES modules, which browsers refuse to load from the filesystem.

The tests need only Node:

node js/core.test.js
node js/extract.test.js

There is no prebuilt Android package to download, and the Capacitor project that produces one is not part of this repository — it is a thin wrapper that copies these same files into a WebView, so anything the app does on Android it does here first.
